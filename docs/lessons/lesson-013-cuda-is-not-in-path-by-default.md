# CUDA is not in PATH by default

**Context:** Building llama.cpp on Jetson.

**Problem:** `nvcc` not found during build.

**Solution:** Add `/usr/local/cuda/bin` to `~/.bashrc`.

**Tags:** `#jetson` `#cuda` `#path`
