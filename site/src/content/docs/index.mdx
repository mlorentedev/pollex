## Why Pollex?

Cloud LLM APIs see everything you type. Every message, every draft, every correction — sent to someone else's servers.

Pollex runs inference on a $99 Jetson Nano with 4GB RAM. Your text never leaves your network. Paste text in the Chrome extension, get polished English back in 3-8 seconds. The output reads like a fluent non-native speaker — professional and clear, not AI-generated.

## Architecture

```
Browser Extension  -->  Cloudflare Tunnel  -->  Go API (:8090)  -->  llama-server (CUDA)  -->  Qwen 2.5 1.5B Q4_0
   (Manifest V3)      (pollex.mlorente.dev)    (7 middleware)        (GPU offload)             (~1GB VRAM)
```

| Layer | Tech | Role |
| --- | --- | --- |
| Extension | Chrome Manifest V3 | Paste text, select model, copy result |
| Tunnel | Cloudflare Tunnel | Zero-config ingress (Jetson behind double NAT) |
| API | Go 1.26, stdlib `net/http` | Routes text to LLM backends, returns polished result |
| LLM | llama.cpp + Qwen 2.5 1.5B Q4_0 | Local GPU inference (~3s short, ~16s long) |
| Monitoring | Prometheus + Alertmanager + Grafana | SLO tracking, alerting, dashboards |

## Performance

Measured on Jetson Nano 4GB, Qwen 2.5 1.5B Q4_0, full GPU offload (`-ngl 999`).

| Text Length | Chars | Inference Time | Throughput |
| --- | --- | --- | --- |
| Short | ~50 | ~3s | ~4 tok/s |
| Medium | ~500 | ~8s | ~4 tok/s |
| Long | ~1000 | ~16s | ~4 tok/s |

SLO targets (7-day rolling window): 99% availability, p50 latency under 20s, p95 under 60s, error rate under 1%.

## Hardening

| Protection | Limit | HTTP Status |
| --- | --- | --- |
| API key | `X-API-Key` header, constant-time compare | 401 |
| Request body | 64KB max | 413 |
| Text length | 10,000 chars | 400 |
| Rate limit | 10 req/min/IP (sliding window) | 429 |
| Request timeout | 120s | 504 |

Middleware chain order: CORS, RequestID, Logging, Metrics, APIKey, RateLimit, MaxBytes, Timeout. Authenticated requests bypass rate limiting by design.

## Quick Start

No GPU needed. The mock adapter returns canned responses for development:

```sh
make dev    # Start API with mock adapter on :8090
make test   # Run 80+ tests with race detector
```
